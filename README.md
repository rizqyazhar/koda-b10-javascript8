# Minitask

Membuat program antrean (queue) dengan memanfaatkan metode Promise dan setTimeOut

Outputnya adalah ketika program dijalankan `console.log()` akan meng-outputkan John -> Ed -> jane. Yang mana John muncul setelah 1.5 detik lalu Ed muncul setelah 2 detik kemudian Jane muncul setelah 500.

Jadi program asynchronous ini dibuat seperti synchronous karena `people` tidak muncul setelah start berbarengan.
